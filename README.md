Now your targeting can have custom icons, animations and even special targets for different players.
---

## 📦 What Does This Module Do?

Custom Target Icon allows multiple target manipulations:

- **Sniper mode** (imitates movement of sniper's scope, speed and max aplitude can be setup)
- **Custom target icon** (you can have one for everyone or individual for each player)
- **Target icon rotation** (clockwise and counterclockwise )
- **Tint** (target icon can be colored)

## 🎯 Installation

### Method 1: Module Browser (Currently unavailable)
1. In Foundry VTT, go to **Add-on Modules**
2. Click **Install Module**
3. Search for **"Alter Ego"**
4. Click **Install**
5. Enable it in your world

### Method 2: Manifest URL
1. Copy this URL: `[manifest URL will be added]`
2. In Foundry, go to **Add-on Modules → Install Module**
3. Paste the URL in **Manifest URL**
4. Click **Install**
